# koneckta.github.io

Public website for **Koneckta Limited**, published with GitHub Pages at [https://koneckta.github.io](https://koneckta.github.io).

## What's here

| File | Purpose |
|------|---------|
| `index.html` | Homepage for Koneckta and the GeoScratch app, with store links and support contact |
| `app-ads.txt` | Authorized sellers file for Google AdMob. It must stay at the root of this site |

The GeoScratch privacy policy lives in a separate repo and is served at [https://koneckta.github.io/documents/](https://koneckta.github.io/documents/).

## Important

- Don't move or rename `app-ads.txt`. AdMob looks for it at `https://koneckta.github.io/app-ads.txt`, based on the developer website listed in the app store listings.
- After changing `app-ads.txt`, click **Check for updates** in AdMob (Apps → All apps → app-ads.txt tab). It can take up to 24 hours to be verified.
- GitHub Pages publishes from the `main` branch, root folder (Settings → Pages).
